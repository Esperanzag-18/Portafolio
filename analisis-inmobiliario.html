Análisis Comercial Inmobiliario

Proyecto de análisis de datos con Power BI

Descripción del proyecto

Este proyecto tiene como objetivo analizar el rendimiento comercial de una empresa inmobiliaria mediante la transformación, modelado y visualización de datos.

Se desarrolló un dashboard interactivo para evaluar las ventas, los ingresos, las comisiones y el comportamiento de los clientes, facilitando la identificación de oportunidades de mejora y la toma de decisiones.

Objetivos del análisis

  • Evaluar el desempeño general de las ventas inmobiliarias.
  • Analizar los ingresos y las comisiones generadas.
  • Comparar resultados por ciudad, tipo de propiedad y canal de venta.
  • Identificar el comportamiento de los diferentes segmentos de clientes.
  • Analizar la evolución de las ventas a través del tiempo.
  • Estudiar las cohortes de clientes según su primera compra.

Herramientas utilizadas

Power BI DAX Power Query Modelado de datos Visualización de datos

Proceso de trabajo

  • Limpieza y transformación de datos mediante Power Query.
  • Construcción de un modelo de datos tipo estrella.
  • Creación de una tabla calendario.
  • Desarrollo de medidas e indicadores con DAX.
  • Análisis temporal y comparación de resultados.
  • Construcción de dashboards interactivos.

Indicadores principales

  • Ingreso total.
  • Cantidad de ventas.
  • Ticket promedio.
  • Comisión total.

Resultados y aprendizajes

El proyecto permitió integrar procesos de preparación, modelado y análisis de datos en Power BI. Se construyeron vistas ejecutivas, comerciales y de cohortes para explorar el comportamiento de las ventas y los clientes.

El proyecto recibió una evaluación favorable del revisor, quien destacó el cumplimiento de los requisitos, la estructura del dashboard, los indicadores y el análisis de cohortes.
