# Proyecto 1: Análisis de clientes de Store 1

## Descripción del proyecto

Este proyecto consiste en limpiar, organizar y analizar información de clientes de una tienda llamada Store 1.

Los datos contienen información sobre los clientes, sus edades, categorías favoritas y gastos realizados en diferentes categorías.

## Objetivo

Preparar los datos para identificar patrones de compra y obtener información útil para la toma de decisiones comerciales.

## Herramientas utilizadas

- Python
- Jupyter Notebook

## Habilidades aplicadas

- Limpieza de datos.
- Transformación de información.
- Creación de funciones.
- Uso de listas y bucles.
- Filtrado de clientes.
- Cálculo de ingresos.
- Segmentación de clientes por categorías.

## Resultados

El análisis permite identificar clientes según su edad, comportamiento de compra y categorías de productos adquiridos.
