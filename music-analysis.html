Project Overview

This project explores music listening behavior using a dataset containing user information, music tracks, artists, genres, cities and listening times.

The objective is to prepare and analyze the data to investigate listening patterns and compare musical preferences between cities.

Project Objectives

  • Explore and understand the dataset.
  • Identify missing values and duplicate records.
  • Clean and prepare the data for analysis.
  • Explore music listening patterns.
  • Compare listening behavior between cities.
