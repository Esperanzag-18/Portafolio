RappiPlus: de datos a decisiones de negocio

Proyecto final de análisis de datos | 2025

Descripción del proyecto

El objetivo de este proyecto es evaluar el desempeño del servicio RappiPlus para apoyar decisiones de negocio basadas en datos.

Se integran datos de pedidos, catálogo de productos, inversión en marketing, comportamiento de usuarios y resultados de un experimento A/B en el proceso de checkout.

El análisis sigue un proceso integral: validar la calidad de los datos, evaluar la rentabilidad, estudiar el funnel de conversión, analizar la retención de usuarios y medir el impacto de cambios en la experiencia de compra.

Objetivos del análisis

  • Evaluar y mejorar la calidad de los datos.
  • Calcular ingresos, costos, inversión en marketing y profit.
  • Identificar los productos y canales con mayor desempeño.
  • Analizar las etapas del funnel de conversión.
  • Estudiar la retención de usuarios mediante cohortes.
  • Evaluar estadísticamente un experimento A/B.
  • Comunicar los resultados mediante un dashboard ejecutivo.

Herramientas y tecnologías

Python Pandas Matplotlib Seaborn SQL PostgreSQL Power BI / Tableau Estadística

Etapas del proyecto

1. Calidad y preparación de datos

Se cargaron y exploraron los datasets de pedidos, catálogo y marketing. Se revisaron valores nulos, duplicados, fechas, variables numéricas y consistencia de los montos. Posteriormente se exportaron los datasets limpios.

2. Rentabilidad del negocio

Se calcularon los ingresos, costos de productos, inversión en marketing y profit. También se analizaron el ticket promedio, la cantidad de productos y el desempeño por categoría y canal.

3. Funnel de conversión con SQL

Se consultó la base de datos para medir los usuarios que avanzan desde la primera visita hasta la compra, identificando las etapas con mayor abandono.

4. Retención por cohortes

Se utilizaron tablas de usuarios y actividad para analizar el comportamiento de los usuarios a partir de su fecha de registro y su actividad posterior.

5. Experimento A/B

Se evaluó si un cambio en la interfaz del checkout generaba una diferencia estadísticamente significativa en la conversión de compra.

6. Dashboard de Business Intelligence

Se planteó una vista ejecutiva con indicadores de ingresos, profit, marketing y ticket promedio, además de una vista de detalle para explorar órdenes y productos.

Conclusiones y aprendizaje

Este proyecto permitió integrar diferentes herramientas y técnicas de análisis de datos para abordar preguntas reales de negocio.

  • Preparación y validación de datos con Python.
  • Evaluación de rentabilidad mediante indicadores financieros.
  • Consultas SQL para analizar conversión y actividad.
  • Análisis de retención mediante cohortes.
  • Aplicación de pruebas estadísticas para evaluar experimentos.
  • Comunicación de resultados mediante Business Intelligence.
